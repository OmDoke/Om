## 🚀 Features

- **Modern UI** — built using Material-UI combined with a sleek, customized dark mode palette
- **Interactive** — responsive, auto-scrolling project carousel (right to left) powered by `react-slick`
- **Dynamic Styling** — custom typography featuring the stylized *Caveat* Google Font
- **Performance** — fast loading and highly optimized using Vite
- **Responsive** — adapts cleanly from desktop monitors to mobile devices

## 🏃 Running Locally

**1. Clone the repository**
```bash
git clone https://github.com/OmDoke/Om.git
cd Om
```

**2. Install dependencies**
```bash
npm install
```

**3. Run the development server**
```bash
npm run dev
```

**4. Build for production**
```bash
npm run build
```
